-🎓 CampusConnect - Event Manager

CampusConnect is a simple Event Management web application built using HTML, CSS, and JavaScript. It helps users manage college events by adding, editing, and deleting event details. The project also includes expense tracking, coordinator management, event reminders, and a countdown timer for upcoming events. All event data is stored using Local Storage, making the application easy to use without a database.

-Features
Add, Edit, and Delete Events
Track Event Expenses
Assign Event Coordinators
Search and Filter Events
Upcoming Event Reminder & Countdown
Local Storage Data Saving
Responsive User Interface
-Technologies Used
HTML
CSS
JavaScript
Local Storage API
